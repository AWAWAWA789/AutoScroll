# 网页自动滚动器 v3.0

一个基于 Python 的 Windows 桌面应用，可自动循环上下滚动网页，适用于长时间浏览长页面、监控面板、社交信息流等场景。

## 功能特色

- **标定或手动**：可通过鼠标左键标定页面长度，也可直接填写滚动次数跳过标定
- **无限循环滚动**：自动在页面顶部和底部之间无限循环滚动，速度、间隔均可调
- **紧急停止**：随时按 `ESC` 键或将鼠标移到屏幕任意角落触发急停
- **手动暂停/继续**：运行界面提供暂停/继续按钮
- **浏览器失焦暂停**：切换离开浏览器窗口时自动暂停，切回后手动恢复
- **单实例运行**：防止重复启动
- **零外部依赖**：鼠标点击检测直接调用 Windows API（`GetAsyncKeyState`），无需额外库

## 系统要求

- Windows 7+
- Python 3.7+（仅源码运行需要）

## 快速使用（推荐）

从 [Releases](../../releases) 下载预编译的 `AutoScroll.exe`，双击运行即可，无需安装 Python。

## 源码运行

```bash
pip install -r requirements.txt
python auto_scroll.py
```

## 使用方法

### 页面布局

```
┌──────────────────────────────────────────┐
│              网页自动滚动器               │
├──────────────────────────────────────────┤
│  参数设置                                 │
│  ┌──────────────────────────────────────┐│
│  │  运行参数                             ││
│  │  运行速度 [500] 行/次 │ 滚动间隔 [15] 秒││
│  │  ─────────────────────────────────── ││
│  │  滚动次数  [0] 次   │  （填 0=使用标定值）││
│  └──────────────────────────────────────┘│
│  ● 未标定                               │
│  [开始标定]  [▶ 开始运行]        [退出]   │
└──────────────────────────────────────────┘
```

### 两种启动方式

**方式一：标定后运行（推荐）**
1. 调整运行参数（速度、间隔）
2. 点击「开始标定」，**切换到浏览器窗口**，等待 3 秒倒计时
3. 页面自动向下快速滚动，到底后**轻点鼠标左键**确认
4. 页面自动滚回顶部，标定完成
5. 点击「▶ 开始运行」启动无限循环

**方式二：直接填写次数（跳过标定）**
1. 在「滚动次数」输入框中填写每轮的滚动步数（如 `20`）
2. 点击「▶ 开始运行」直接启动，无需标定

### 运行界面

```
┌──────────────────────────────────────────┐
│  [停止]         运行监控                  │
├──────────────────────────────────────────┤
│  ● 运行中                                │
│  ↓ 第1轮向下: 5 / 20 次                  │
│  已循环: 0 轮（无限循环，点击「停止」结束）│
│  时间: 00:01:23                          │
│  [暂停]                      [停止运行]  │
└──────────────────────────────────────────┘
```

- **每轮**：向下滚动到底 → 等待若干秒 → 向上滚回到顶 → 等待若干秒
- **轮次无限**：`已循环: N 轮` 持续递增，永不停止

### 安全机制

| 操作 | 效果 |
|------|------|
| `ESC` 键 | 立即停止 |
| 鼠标移到屏幕任意角落 | 立即停止 |
| 点击「暂停」按钮 | 手动暂停，再次点击恢复 |
| 切换浏览器窗口 | 自动暂停，切回后需手动点击「继续」|

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 运行速度 | 500 行/次 | 每次滚轮滚动的行数，值越大滚动越快 |
| 滚动间隔 | 15 秒 | 每次滚动之间的等待时间 |
| 滚动次数 | 0 | 每轮向下/向上的步数（0 = 使用标定值）|

标定阶段使用固定参数：速度 1000 行/次，间隔 0.1 秒，确保快速完成标定。

## 打包成 EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name AutoScroll auto_scroll.py
```

生成的 exe 位于 `dist\AutoScroll.exe`。

## 依赖库

- [pyautogui](https://github.com/asweigart/pyautogui) — 模拟鼠标滚轮和屏幕检测
- tkinter（Python 内置）— GUI 界面

> mouse 库已移除，鼠标点击检测改用 Windows API `GetAsyncKeyState`，更稳定且零额外依赖。

## 注意事项

- 标定时请确保鼠标停留在页面内容区域，不要点击浏览器滚动条
- 运行期间不要手动滚动页面，否则会与程序冲突
- 本工具仅支持 Windows（使用了 Windows API）
- 建议在运行前关闭不必要的后台程序以避免干扰
